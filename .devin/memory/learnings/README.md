# Learnings

Insights and discoveries about the trade system made during development and operations.

## Purpose
Learnings capture valuable insights about system behavior, effective approaches, and important discoveries that can inform future work.

## Learning Entry Template

```markdown
# Learning: [Topic]

## Date
YYYY-MM-DD

## Context
What situation or task led to this discovery?

## Discovery
What was learned or discovered?

## Why It Matters
Why this insight is important and how it affects future work.

## Application
How to apply this learning in future situations.

## Related
Links to related learnings, documentation, or code.

## Tags
topic, system-area, discovery-type
```

## Adding Learnings

When discovering something valuable:
1. Create a new file with format: `topic-description.md`
2. Document the insight clearly and specifically
3. Explain the context and why it matters
4. Describe how to apply it in the future
5. Add relevant tags for discoverability
