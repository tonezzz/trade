# Remote Access Agent Skill

## Description
A skill for overcoming physical access barriers when you cannot directly access remote screens or machines. Provides automated remote access, troubleshooting, and service management capabilities.

## Capabilities
- Remote service management without GUI access
- Network troubleshooting and connectivity checks
- Service status monitoring via API/CLI
- Automated remote command execution
- Cross-machine file operations
- Remote deployment and updates
- Barrier-free system administration

## Use Cases
- **Remote Service Management**: Manage services on machines you can't physically access
- **Network Troubleshooting**: Diagnose connectivity issues without GUI
- **Service Deployment**: Deploy and update services remotely
- **Status Monitoring**: Check service health without web interfaces
- **File Operations**: Transfer and manage files across machines
- **Emergency Access**: Handle critical issues when physical access is blocked

## Usage
Invoke this skill when you need to:
- Manage services on a remote machine you can't access physically
- Troubleshoot network or service issues without GUI access
- Deploy updates to remote systems
- Check service status via alternative methods
- Perform file operations across machines

## Example
```
"Use remote access agent to check the trade service on tony-dell"
"Deploy the API update to the remote machine without GUI access"
"Troubleshoot why the trade page isn't working remotely"
"Check service status on tony-dell without physical access"
```

## Barrier-Crossing Techniques
- SSH-based remote command execution
- API-based service management
- Network diagnostics and troubleshooting
- Remote file transfer and management
- Service restart and monitoring via CLI
- Log analysis without GUI access
