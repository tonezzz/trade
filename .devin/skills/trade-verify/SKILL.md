# Trade System Verification Skill

## Description
A skill for comprehensive verification of the trade system including database status, API health, data quality, UI functionality, and deployment status.

## Capabilities
- Database verification (tables, records, data quality)
- API health checks (endpoints, connections, response times)
- Data validation (completeness, quality, freshness)
- UI functionality testing (all deployed UIs)
- Deployment verification (Docker containers, Caddy routing)
- Configuration validation (environment variables, API keys)
- Performance monitoring (response times, resource usage)

## Use Cases
- **System Health Check**: Verify entire trade system is operational
- **Post-Deployment Verification**: Confirm deployment was successful
- **Data Quality Audit**: Check data integrity and completeness
- **API Testing**: Verify all endpoints are working correctly
- **UI Verification**: Test all trading UIs are accessible and functional
- **Configuration Validation**: Ensure all settings are correct

## Usage
Invoke this skill when you need to:
- Verify the trade system is working correctly
- Check after making changes to the system
- Audit data quality and completeness
- Test API endpoints and UI functionality
- Validate deployment and configuration

## Example
```
"Use trade verification to check the entire system health"
"Verify all API endpoints are working after the latest changes"
"Check data quality and completeness for all currency data"
"Test all trading UIs are accessible and functional"
"Validate deployment and configuration settings"
```

## Verification Areas
- **Database**: Tables, records, data quality, connections
- **API**: Endpoints, health checks, response times, error handling
- **Data**: Completeness, quality, freshness, validation
- **UI**: Accessibility, functionality, data display, responsiveness
- **Deployment**: Docker containers, Caddy routing, service status
- **Configuration**: Environment variables, API keys, settings files
